How do I make App Store screenshots?

Question: How do I make App Store screenshots?
Answer: Add a background and a short caption to a real app capture, then export it in a size accepted by your target store.

Start with a real capture

Upload PNG, JPEG, or WebP images. Use a capture from each device type so its layout stays recognizable. Choose “Show full image” if you need every edge of the capture visible.

Update the next release

Choose Replace capture to keep your background, frame, and text. Compare it with the previous capture, then export only the files that changed since your last export.

Check each language

Add a language and translate your captions where supported. Replace the capture separately if the app interface is translated. Review line breaks at each export size before downloading the set.
